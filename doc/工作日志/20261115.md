# 2026/11/15 工作日志

本次更新发行``2.4.76``版本。

### 微调了项目架构

我移除了还未实现的``file.st``以及相关内容。并将``test/test.cpp``重命名为``test/Test.cpp``。

### 修复了一个致命漏洞

以往的``AstRunner``会把``AstLeaf*``强转成``AstIdentifier*``并进行读取，这是错误操作，但是因为编译器在``x86_64``架构下``AstLeaf``和``AstIdentifier``的内存布局是一致的，所以该问题之前一直没有发现。该问题直到我尝试将``Stamon 2.4.75``移植到``WASM``后才显露出来。

与此同时，我也发现``AstIdentifier``其实并没有在项目中真正被用到，因而我修复了``AstRunner``中对``AstLeaf*``的成员读取、移除了``AstIdentifier``并把``AstIdentifierName``重命名为``AstIdentifier``。

介于此漏洞在其他编译器或其他架构中极易造成崩溃，我选择修复并直接发行新的版本。
